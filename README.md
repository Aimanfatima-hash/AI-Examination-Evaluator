# AI Examination Evaluator

An AI-assisted examination answer-sheet evaluation system built using Python, Flask and Google's Gemini API.

## Project Overview

The AI Examination Evaluator is designed to assist teachers in evaluating examination answer sheets. It uses AI to analyse student responses against a provided answer key and marking scheme, helping reduce repetitive manual checking.

The system is intended to support teachers, not replace their judgement.

## Key Features

- Upload examination answer sheets.
- Upload question papers and answer keys or marking schemes.
- AI-assisted evaluation using Google's Gemini API.
- Question-wise marks and explanations.
- Total marks and percentage calculation.
- Review flags for answers that may require teacher attention.
- Browser-based camera capture for scanning an answer-sheet page.

## How It Works

1. The teacher uploads an answer sheet.
2. The question paper and marking scheme are provided.
3. The backend processes the submitted documents.
4. Google's Gemini API assists in evaluating student responses.
5. The application displays question-wise marks and evaluation results.
6. The teacher can review uncertain evaluations.

## Technologies Used

- **Python:** Core programming language.
- **Flask:** Web application framework.
- **HTML and CSS:** User interface.
- **Google Gemini API:** AI-assisted answer evaluation.
- **Git and GitHub:** Version control and project hosting.

## Current Project Status

This project is a working prototype under development.

The current implementation supports document uploads and single-page camera capture. Further development and testing are needed before practical school-wide implementation.

## Limitations and Future Improvements

- Support for multi-page camera scanning.
- More extensive evaluation accuracy testing across subjects.
- Improved handling of handwritten answers and scanned documents.
- Teacher correction and feedback features.
- Better error handling and application security.
- Testing with larger sets of examination papers.

**Important:** AI-generated marks should be reviewed by a teacher before being used as official examination results.
